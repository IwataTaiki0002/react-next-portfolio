# トップページ設計書

## 概要

トップページは、ポートフォリオサイトのランディングページです。ヒーローセクションでサイト全体の目的を伝え、About/Works/Blog/Contactの4つのセクションで各ページへの導線を提供します。2026/01/24時点で、青グラデーション背景・プロフィールプレビュー表示に対応しています。

## 3. データフロー

### 3.1 データ取得

```tsx
const [blogData, worksData, profileData] = await Promise.all([
  getBlogList({ limit: TOP_BLOG_LIMIT }),
  getWorksList({ limit: TOP_WORKS_LIMIT }),
  getProfileList({ limit: 1 }),
]);
```

### 3.2 使用定数

- `TOP_BLOG_LIMIT`: 2件
- `TOP_WORKS_LIMIT`: 3件
- プロフィール: 1件

### 3.3 HTMLタグ除去

```tsx
const stripHtml = (html: string) => {
  return html.replace(/<[^>]*>/g, '').replace(/&nbsp;/g, ' ').trim();
};
```

## 4. セクション詳細

### 4.1 ヒーローセクション

**表示要素**
- たい焼き画像（160px・円形・影付き）
- タイトル: "Welcome to my Portfolio!"
- 説明文: エンジニア志望・制作物発信

**スタイル**
- 背景: 透過（body の青グラデーションが見える）
- テキスト色: 白
- パディング: 200px（PC）/ 120px（モバイル）

### 4.2 Aboutセクション

**表示要素**
- タイトル: "About"
- 説明文
- プロフィールプレビューボックス
  - プロフィール画像（円形・100px）
  - 名前・役職
  - プロフィール文の冒頭（120文字・HTMLタグ除去済み）
- ボタン: "プロフィールを見る" → `/profile`

**スタイル**
- プレビューボックス: 横並び・薄いグレー背景・角丸

### 4.3 Worksセクション

**表示要素**
- タイトル: "Works"
- 最新作品3件（カードグリッド）
- ボタン: "作品一覧を見る" → `/works`

### 4.4 Blogセクション

**表示要素**
- タイトル: "Blog"
- 最新記事2件（カードグリッド）
- ボタン: "記事一覧を見る" → `/blog`

### 4.5 Contactセクション

**表示要素**
- タイトル: "Contact"
- 説明文
- お問い合わせプレビューボックス
  - mail.png画像（100px）
  - お問い合わせ説明文
- ボタン: "お問い合わせ" → `/contact`

**スタイル**
- プレビューボックス: Aboutと同じスタイル
